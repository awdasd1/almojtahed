# 📚 المكتبة الشاملة — الجيل الرابع (الذكاء الاصطناعي والبحث الهجين)

تطبيق متطور للبحث الدلالي العصبي والهجين في التراث الإسلامي، مدعوم بمحرك المتجهات **Qdrant**، ونماذج التضمين والفرز المتقاطع (BGE-M3 / Badr Embedding / Cross-Encoders)، مع داشبورد ذكاء اصطناعي تفاعلي وهوية بصرية مستوحاة من **Claude Web**.

---

## 🚀 النشر السريع عبر كلويفي (Coolify Deployment)

تم تصميم هذا المستودع ليكون فائق الخفة ومستعداً بالكامل للنشر التلقائي عبر **Coolify**:

### 1. الإعداد في Coolify
1. افتح لوحة تحكم **Coolify**.
2. اختر **+ Create New Resource** -> **Public/Private GitHub Repository**.
3. حدد هذا المستودع. سيتعرف Coolify تلقائياً على ملف `docker-compose.yml` أو `Dockerfile`.
4. اختر نوع النشر: **Docker Compose** (يوصى به لتشغيل Qdrant وتطبيق الويب معاً بتناغم).

### 2. التحديث التلقائي التلقائي (Automatic Updates)
* في إعدادات التطبيق داخل Coolify، فعّل خيار **Webhook** أو **Autodeploy on Push**.
* انسخ رابط الـ Webhook وضعه في إعدادات مستودعك على GitHub تحت:
  `Settings` -> `Webhooks` -> `Add webhook`.
* بمجرد إرسال أي تعديل برمجى عبر `git push`، سيقوم Coolify بإعادة بناء الحاوية وتحديث الموقع لجميع المستخدمين تلقائياً وبدون توقف عن العمل (Zero-downtime Deployment).

## 💾 إدارة البيانات والتخزين الدائم (Persistent Storage)

لا يتم تضمين قواعد البيانات الضخمة (الـ Snapshot وفهارس المتجهات) داخل مستودع Git للحفاظ على خفته وسرعة تحميله. بدلاً من ذلك، تُدار البيانات عبر الآليات التالية:

### المتغيرات البيئية الاختيارية (Environment Variables):
يمكنك إضافة هذه المتغيرات في لوحة تحكم Coolify أو ملف `.env`:

| المتغير | الوصف | مثال |
| :--- | :--- | :--- |
| `HF_DATASET_REPO` | اسم مستودع البيانات على Hugging Face لسحب القواعد تلقائياً عند أول تشغيل | `username/shamela-corpus-db` |
| `HF_TOKEN` | رمز الدخول الخاص بحساب Hugging Face (إذا كان المستودع خاصاً Private) | `hf_...` |
| `QDRANT_URL` | رابط خادم Qdrant الداخلي أو السحابي | `http://qdrant:6333` |
| `PORT` | منفذ تشغيل خادم الويب (افتراضياً 8000) | `8000` |

> 💡 **ملاحظة:** تستخدم خدمة Docker Compose وحدات تخزين دائمة (`shamela_qdrant_volume` و `shamela_data_volume`)، مما يضمن بقاء البيانات محفوظة في السيرفر دائماً حتى مع إعادة تشغيل أو تحديث الحاويات.

## 🐳 التشغيل المحلي السريع عبر Docker Compose

لتشغيل المشروع محلياً أو على أي سيرفر مستقل:

```bash
docker compose up -d --build
```

ثم افتح المتصفح على:
👉 `http://localhost:8000`
وللوصول إلى لوحة تحكم Qdrant:
👉 `http://localhost:6333/dashboard`
